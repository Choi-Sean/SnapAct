# 템플릿 자리

레이아웃 템플릿(배경 이미지 + 슬롯 정의)을 여기에 넣습니다. 직접 제작 예정이며,
`synth/layouts.py`의 `Template`/`Slot` 인터페이스만 맞으면 다른 파일은 손댈 필요 없습니다.

필요한 최소 구성 — 클래스당 최소 3종 이상 권장 (레이아웃이 하나뿐이면 모델이
"그 레이아웃"을 외웁니다):

| gate_class | 템플릿 예시 |
|---|---|
| `id_document` | 주민등록증, 운전면허증, 여권 데이터 페이지(MRZ 포함), 외국인등록증 |
| `payment_card` | 신용카드 앞면(엠보싱/평면), 뒷면(마그네틱+서명란), 체크카드 |
| `medical_record` | 처방전, 진료비 영수증, 약봉투 라벨, 검사 결과지 |
| `financial_doc` | 통장 내지, 거래내역서, 급여명세서, 세금계산서 |

**실제 신분증/카드 이미지는 여기에 넣지 않습니다.** 배경/레이아웃은 직접 그리거나
공개 서식을 사용하고, 내용물은 생성기가 무작위로 채웁니다.
